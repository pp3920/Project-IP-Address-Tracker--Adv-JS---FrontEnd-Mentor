

** IP Address Tracker**

An interactive web application that allow users to track the location of IP Address or domain in real time.
It is built using HTML, CSS, JavaScript and Leaflet.js for usage of map visualization.

A simple and interactive web application that allows users to track the location of any IP address or domain in real-time. Built using HTML, CSS, JavaScript, and Leaflet.js for map visualization.



* Features*

=> Search for any IP address or domain
=> Displays location (City, Region)
=> Shows timezone
=> Displays ISP (Internet Service Provider)
=> Real-time API data fetching



* Tech Stack*

=> HTML5
=> CSS3
=> JavaScript
=> Leaflet.js (for maps)
=> IPify API (for IP geolocation)




*What I Learned*

=> Working with APIs using `fetch()`
=> Handling asynchronous JavaScript (Promises)
=> DOM manipulation and event handling
=> Integrating maps with Leaflet.js
=> Error handling in real-world applications
